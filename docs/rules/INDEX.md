# Rules corpus — INDEX

Consolidated, ID-tagged restatement of the official rulebooks in `docs/rules/*.pdf` (local only — git-ignored), written as the
foundation for backend design. Start with `base.md` §10 (mechanics model); each expansion is a delta.

| File | Contents |
|---|---|
| [`base.md`](base.md) | Base game: glossary, full card/Wonder/token data, rules (`B-…`), mechanics model (§10), open questions, reference-implementation discrepancies |
| [`agora.md`](agora.md) | Agora (official, 2020): Senate, Senators, Conspiracies, Decrees, political supremacy (`A-…`) |
| [`pantheon.md`](pantheon.md) | Pantheon (official, 2016): Divinities, Pantheon activation, Grand Temples, tokens (`P-…`) |
| [`extra-wonders.md`](extra-wonders.md) | Extra Wonders (community "77 Wonders"): 61 new Wonders, the mechanics they introduce (`X-…`) |

Open questions are tagged `[OPEN-<doc><n>]` and tabulated at the end of each file.
